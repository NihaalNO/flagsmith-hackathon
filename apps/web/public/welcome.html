Questions

About code access, AI models and what Seshat changes.

Which languages does Seshat read?

TypeScript and JavaScript, including TSX and JSX. Flags read from other languages don't show up as references yet.

Does Seshat change my code or Flagsmith?

It never pushes code: cleanup patches wait for your review. In Flagsmith it creates a flag only when you launch a suggested experiment, and never edits or archives one.

What can the GitHub App see?

Contents, metadata and organization members, all read-only. It has no permission to push.

Which AI model does Seshat use?

The one you configure: Groq, Anthropic or any OpenAI-compatible server. A reason that cites a file Seshat never read is rejected.

How do experiment events reach Seshat?

Your app posts exposures and conversions to the Seshat API with the experiment's key.
